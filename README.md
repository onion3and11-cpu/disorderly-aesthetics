# 失序美學：時代迴廊

《失序美學：時代迴廊》是一款以不同藝術年代與畫派為核心的網頁動作遊戲。

## 遊戲特色
- 多個藝術年代關卡
- 五種畫派武器與各自專屬大絕
- 主動技能、天賦構築、成就系統
- 地圖特殊奇物與方向指示
- Boss 戰、黑市、升級、難度選擇
- 舒適化畫面：降低震動與戰鬥浮字干擾

## 操作
- WASD：移動
- 滑鼠左鍵：攻擊
- 1–5 / 滾輪：切換畫派
- Space：閃避
- Q：目前畫派專屬大絕
- E / R / F / C：主動技能
- B：黑市
- ESC / P：暫停
